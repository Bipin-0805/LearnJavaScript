# Variables in JavaScript
    Variables are labelled box which are used to store data.
    In Javascript we use 3 keywords to create a Variable. i.e

- var
- let
- const

## var 
    Historical, less prefered. Variables declared with this keyword are declared globally this is no restriction of block scope.variables can be reassigned and redeclared using this keyword. i.e

    var username = "Bipin";    // declared and assigned(initialized)
    username = "Gaurav";        // reassigned
